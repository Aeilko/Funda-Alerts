# Funda Alerts

## Steps
1. Create `settings.json` from example file
2. Get Telegram bot API token
3. Get Chat ID of chat with bot
4. Install requirements
    - In my case `source .venv/bin/activate && pip install -r requirements.txt`
5. Manually add the `funda_scraper` folder from the [funda-scraper](https://github.com/whchien/funda-scraper) repo
6. Run `funda_checker.py`
